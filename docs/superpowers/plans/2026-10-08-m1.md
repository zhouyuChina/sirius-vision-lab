# M1 Implementation Plan

Goal: deliver the synchronous recognition service and review console described in README.md and docs/TASK-BREAKDOWN-mvp.md.
Architecture: injected asynchronous chat adapter, versioned schema templates, SQLite WAL repository, guarded image loader, API and cookie-authenticated zero-build admin.
Tech: Python 3.12, uv, FastAPI, httpx, jsonschema; standard-library SQLite/scrypt.

## Constraints and interfaces
- Env-only endpoints and secrets; MiniMax primary, Kimi backup, GLM third selectable via VISION_PROVIDER; no automatic cross-provider retries.
- Provider.complete(prompt, image, preferred_model) returns content/model/provider/usage/latency.
- Template.parse(raw) strips reasoning before extracting and validating JSON.
- Storage persists one record per accepted analysis with content-addressed image reference.
- Admin-role keys are separate from ordinary keys. Session writes require a session-bound CSRF header and same-origin check.
- White-label error envelopes omit input values and exception details.

## Review focus
DNS rebinding/redirects; error reflection of provider or input data; session expiry/CSRF; cursor ordering on identical timestamps; provider retry and parser retry accounting. Tests cover these boundaries, plus malformed/oversized input.
